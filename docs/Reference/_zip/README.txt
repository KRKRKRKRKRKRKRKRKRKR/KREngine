KR エンジン リファレンス(KREngine Reference)

■ 開き方
  1. この Zip を、好きな場所に展開します(右クリック →「すべて展開」)。
  2. 展開したフォルダーの reference.html を、ダブルクリックします。
     ブラウザ(Edge・Chrome など)で開きます。
  ※ Zip の中のまま開くと、正しく表示されないことがあります。必ず展開してから開いてください。

■ 中身
  reference.html            リファレンスの本体(1 つのファイル)。目次・機能ごとのページ・関数の検索つき
  README.txt                この説明
  THIRD_PARTY_LICENSES.txt  reference.html の中に入れてある、ほかの人が作った部品のライセンス

■ インターネットが無くても見られます
  表示に使う部品(Markdown の表示 = marked・コードの色 = highlight.js・図 = Mermaid)は、
  reference.html の中に入れてあります。
  インターネットにつながっていないときは、文字の形(フォント)だけ、パソコンにある物
  (游ゴシック・メイリオ・Consolas など)になります。中身は同じです。

■ 版
  このリファレンスは、KR エンジンの、ファイル名に書いてある版のものです(例 v0.14.0)。
  エンジンの版が変わったら、新しい Zip を使ってください。
  元の資料(Markdown)は、KREngine のリポジトリの docs/Reference/ にあります。
